EXT-07 当前状态 documented Claude Code 2.1.247 非计数 companion

把会话输出发成一张活页

Claude Code 先把输出写成单页，再通过权限门发布到 claude.ai。新页默认只让作者看。后续改动沿用同一 URL 并留下版本，分享范围、查看者自己的 MCP 权限和组织策略共同决定别人最终看到什么。O

这张页没有后端，不能保存表单状态。这里的持久化指托管 URL、版本、图库和保留期。会话怎样从 Web 接到终端，见 CLOUD-01 主页面。OI

SESSION OUTPUT / PUBLISH PROOF

同一链接，逐版更新

  1. 会话写出临时 HTML 或 Markdown
  2. 权限模式审查上传动作
  3. claude.ai 建立默认私有 URL
  4. 每次再发布形成一个新版本
  5. 分享控件选受众和可见版本

发布是远端写入。没有登录与政策放行时，流程停在本地文件或拒绝提示。

01 / TERMS

四种证据，三个角色

本页主要依赖官方契约。当前 Codex 环境找不到 claude 可执行文件，发布又会写远端，所以没有把给定版本或产品路径包装成本机已验证事实。

O官方契约

Anthropic 产品文档、博客与官方 API 资料，说明公开支持范围。

L本机证据

本轮命令只证明当前 shell 没有找到 Claude Code，无法核对帮助入口。

R真实实验

本轮没有。创建链接会登录、上传并写入 Anthropic 托管端。

I研究推断

用来区分页面版本持久化和应用数据持久化，缺口仍保留为未知。

作者会话

读取代码、对话和已连接工具，生成单页源文件并发起发布。O

claude.ai 托管端

保存 URL 与版本，提供浏览器查看、图库、受众控制和组织策略。O

查看者账户

决定实时 MCP 能读到什么。连接、批准和外部工具权限都属于查看者。O

02 / SEQUENCE

一次发布怎样走完

动作从会话认为视觉页更合适开始，停在私有链接已经生成。分享是后续选择，不是首次发布的默认结果。

T0

提出页面

用户可以直接要求 artifact，Claude 也可能在输出适合单页时发起。O

T1

写出源文件

没有点名路径时，Claude 在项目外的临时目录写 HTML 或 Markdown。O

T2

经过权限门

Auto 交给分类器审查。Manual 与 Accept edits 要用户批准上传。O

T3

预览私有 URL

首次发布后终端显示地址并打开浏览器。页面此时只有作者能看。O

T4

再发布或分享

修改后沿用原 URL 形成版本。作者再从页头选择受众和查看版本。O

04 / LIMITS

发布前后各有门

套餐、登录、模型提供商和组织政策决定能否生成链接。页面建成以后，受众、连接器开关、保留期和网络白名单继续限制它。

发布资格

当前专页要求 Pro、Max、Team 或 Enterprise、claude.ai 登录、Anthropic API，以及 CLI 2.1.183 以上。API key、gateway token 与云提供商凭据不能发布。O

组织与合规停止点

CMEK、HIPAA 或 ZDR 会阻止发布。Enterprise 要由 Owner 开启，Team 默认开启。用户还能从设置、环境变量或权限拒绝规则关闭 Artifact。O

页面能力

源文件限 HTML、HTM 或 Markdown，渲染后不能超过 16 MiB。页面没有后端，不能自己认证，也不能保存表单输入。O

分享与连接器

Team 与 Enterprise 的公开分享默认关闭。带实时 connector 的页在任何套餐都不能公开，Owner 还可以单独关闭 artifact connector。O

发布失败

条件未满足时，Claude 留下本地 HTML，或明确说不能发布。

公开访问被挡

Owner 关闭 External sharing 后，既有公开链接会被阻断，原受众设置仍保留；传播与缓存失效时序没有公开承诺。

删除

保留期可自动清理。组织也能用 Compliance API 删除明确的 artifact。

作者怎样撤销单个分享仍缺公开步骤

Claude Code 专页说明页头 Share 控件、受众选择、组织级外部分享开关和合规删除，却没有写出作者把单个组织内分享恢复为私有的逐步操作。本页不借用普通 Claude 对话 artifact 的 Unshare 文案补空白。OI

05 / EXPERIMENT

命令核对停在入口外

本轮只运行无副作用命令。shell 没有找到 claude，可见基线来自任务冻结值，不能冒充当前环境的版本回显。

实际运行的命令

  • claude --version
  • claude --help
  • claude mcp --help
  • command -v claude

前三条返回 command not found，路径查询没有结果。它只能证明当前独立 Codex 环境的 PATH 中没有 Claude Code。L

为什么没有继续

真实发布需要登录、上传产物并在 Anthropic 端创建对象。查看分享与 MCP 还会触及账号、组织和外部数据权限。任务明确禁止这些动作。

07 / UNKNOWNS

公开契约还缺四块

这些空白会影响撤销、缓存和多人编辑。页面只写到证据能托住的位置。

01单个分享怎样撤销

作者把某位组织成员或组织全员移出受众的逐步操作没有写进 Claude Code 专页。

02公开链接的缓存时序

Owner 关闭 External sharing 后访问会被挡，边缘缓存和浏览器缓存何时失效没有公开契约。

03临时源文件寿命

项目外临时目录里的 HTML 或 Markdown 何时清理，崩溃后是否保留，官方没有说明。

04多人并发发版

两个编辑者同时发布时怎样排序、冲突和恢复，公开页面没有给出一致性规则。

01 准备

使用专用测试组织、一次性仓库与无敏感信息的账号，记录版本和哈希。

02 首次发布

在 Manual 模式生成小型单页，核对批准、URL、浏览器和图库条目。

03 再发布

改一处文字后重发，核对 URL 不变、版本增加和打开页面原地更新。

04 两种 MCP

分别用项目 MCP 和 claude.ai connector，核对构建快照与查看时取数。

05 查看者

用已连接、未连接和拒绝授权的测试账号比较实时区域。

06 撤销

关闭测试组织的外部分享并核对旧链接。删除只针对明确的一次性 artifact。
