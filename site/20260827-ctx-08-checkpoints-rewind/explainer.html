文件检查点、rewind 与回退边界

代码和对话可以分开回卷

OClaude Code 把每次用户提示当作恢复点。它用文件编辑工具动手前，会保留受影响文件的旧内容。用户随后可把代码、对话或两者拉回所选提示，也可只压缩一段对话。

OShell 命令已经改掉的文件、数据库写入、API 调用和部署都不会跟着回来。回退只覆盖它确实记录过的文件编辑。

01 · TERMS

先分清四件东西

提示检查点

每次用户提示形成一个可选择的恢复位置。菜单按本次会话里的提示排列。

文件快照

文件编辑工具写入前保存旧内容。它服务于代码恢复，和 Git 提交没有从属关系。

对话回退

对话被截回所选消息，磁盘文件可以保持当前状态。恢复后的原提示会回到输入框。

定点摘要

压缩所选位置之前或之后的消息，文件不变，原消息仍留在会话记录里。

02 · SEQUENCE

一次动作怎样走完

T0

用户发送提示

新提示成为菜单里的恢复点。

T1

Claude 选择工具

读取和推理本身不产生可恢复的文件改动。

T2

写入前留快照

文件编辑工具动手前保存旧内容。SDK 文档明确列出 Write、Edit 与 NotebookEdit。

T3

文件发生变化

新建文件和改过的文件进入这次会话的跟踪范围。

T4

用户打开回卷菜单

输入框为空时按两次 Esc，或运行 /rewind。

T5

用户选恢复方式

代码、对话、两者或摘要，各自改变不同状态。

停止条件

O所选检查点以后没有被跟踪的文件改动时，菜单不会显示两项代码恢复动作。链接文件被跳过时，恢复结束并给出跳过数量，文件保留当前内容。

04 · LIMITS

回卷越过不了这些边界

OBash 改过的文件

rm、mv、cp、重定向和 sed -i 造成的变化不进文件检查点。对话回去以后，这些结果仍在。

O远端系统

数据库写入、API 请求和部署无法被本地检查点撤销。权限规则负责在执行前拦截或询问，rewind 负责事后恢复已跟踪文件。

O外部与并发编辑

用户手改和其他并发会话的编辑通常不被当前会话捕获。官方只保留一个例外，双方碰巧改到当前会话已跟踪的同一文件时，结果可能被卷入。

Osubagent 编辑

大多数 subagent 改动不会随父会话恢复。前台运行的 forked skill 是官方列出的例外，后台 fork 和其他 subagent 需要用 Git 或手工撤销。

O符号链接与硬链接

Claude Code 2.1.216 起会跳过链接路径，并报告跳过数量。被跳过的文件保持当前内容。

O长期历史

检查点服务于会话级快速恢复。协作、审计和长期版本仍交给 Git。当前官方页面写明每个会话保留最近一百个检查点的文件快照。

06 · IMPLEMENTATION

CLI 自动记录，SDK 需要显式打开

Claude Code CLI

恢复点跟着用户提示自动产生。文件编辑工具写入前保存受影响文件，检查点和会话一起保存，恢复会话以后仍可使用 /rewind。默认清理周期跟随会话，为三十天，可由 cleanupPeriodDays 调整。

Agent SDK

调用方需要打开文件检查点，接收用户消息里的检查点标识，再调用文件恢复方法。SDK 只承诺跟踪 Write、Edit 与 NotebookEdit。文件恢复不改对话上下文。

版本边界

O2.1.191 起，用户可在同一进程里从 /clear 之前的会话入口恢复。2.1.216 起，文件恢复会跳过链接和其他非普通文件。2.1.247 的官方 changelog 修复了指定 agent 会话中“从这里摘要”使用错误系统提示的问题。

L研究固定基线是 2026-08-27 的 2.1.247 与 202 个官方入口。2026-08-28 核对时，当前命令已指向 2.1.248，官方入口也增至 203。页面没有把次日安装当作基线实验。

07 · UNKNOWNS

还不能写死的地方

I恢复的原子性

官方没有说明多文件恢复中途崩溃时，已经恢复和尚未恢复的文件怎样收尾。

I同文件并发冲突

官方说并发编辑通常不捕获，又提到同一被跟踪文件的例外。外部写入与快照冲突时谁优先，公开契约没有细化。

I本机存储布局

本轮遵守隐私边界，没有查看会话记录与文件历史目录。具体快照命名、去重与占用空间留作未知。

I最近一百点以外

官方说明旧检查点会丢弃不再引用的快照，也保留首个文件基线。复杂交叉编辑下哪些文件还能完整恢复，需要隔离实验。

安全复现步骤
  1. 在一次性目录启动新的交互会话，先确认不会产生远端写入。
  2. 让 Claude 用文件编辑工具新建一个文件，再用 Bash 新建另一个文件。
  3. 输入框留空，按两次 Esc，选到本次提示以前的恢复点。
  4. 先选只恢复代码，比较两个文件，再单独测试只恢复对话和两者一起恢复。
  5. 记录菜单、文件摘要与退出状态，不保存提示正文、工具参数或会话标识。

这套实验会发起模型请求，本轮没有执行。执行者还需确认当前认证对应的订阅额度或 API、云提供商计费，并使用隔离目录，避免碰到真实项目和并发会话。
