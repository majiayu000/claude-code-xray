四个角色

先分清谁做什么

页面把宿主应用、Claude Code 运行时、MCP server 和工具处理函数分开。官方接口能证明职责，进程间私有帧仍留作未知。

01

SDK 宿主

开发者在这里注册工具和 server，发起查询，并提供审批界面、Hook 与自定义处理函数。

02

Claude Code 运行时

把工具面送入模型上下文，按规则处理候选调用，并把工具结果送回循环。

03

MCP server

发布工具名称和输入 schema。它可以在进程内，也可以通过 stdio、HTTP 或 SSE 连接。

04

处理函数

接收已校验参数，执行应用逻辑，再返回内容块与错误标记。TypeScript 还可附带结构化数据，Python 进程内 server 不转发这个字段。

O官方契约文档、仓库、changelog
L本机静态证据固定二进制与帮助
R真实实验本轮没有付费运行
I研究者推断只用于连接公开事实

注册、发现和获准调用是三个不同状态。宿主把 server 交给 SDK 后，运行时还要等连接与工具表就绪。工具出现在上下文里，只表示 Claude 可以提出请求。它若没有命中预批准规则，仍会停在权限判断或宿主回调。这个区分解释了为什么 server 已经配置，某个工具仍可能暂时不可见，也解释了工具能够被看见却不能直接执行的情况。 O

一次调用

六步走完一趟

主要动作是开发者配置工具治理并发起一次查询。时序跟到工具结果返回；会话管理与最终结构化结果属于 SDK-01。

01

开发者发起查询

开发者把 MCP server、Hook、审批回调和工具面选项交给 SDK，再调用 query()。注册完成只说明工具可供发现，调用仍要过审批。 O

02

Claude 提出候选调用

请求带着工具名和输入进入前置 Hook。MCP 工具名带有 server 与 action 两段标识，完整形式见代码 mcp__服务名__工具名。 O

03

前置 Hook 先看

前置 Hook 可以改输入、拒绝、要求审批或暂缓，对应事件名为 PreToolUse。显式拒绝会让处理函数停在门外。 O

04

权限链继续判断

deny、ask、权限模式与 allow 规则依次处理。普通调用在前面获批会跳过 canUseTool；ask 规则、要求用户交互的 MCP 工具和 plan 模式的写操作会把决定交给宿主与用户。关键路径上的 rm 或 rmdir 依模式进入回调、分类器或拒绝路径。 O

05

获批后执行

内置工具进入运行时执行层，自定义工具交给 MCP 处理函数。连接或参数问题会转成失败路径。 O

06

结果回到 Claude

成功触发后置 Hook，失败触发失败 Hook。结果送回模型，Claude 可以继续、改道或结束。 O

权限、失败与停止

三种出口

工具调用失败通常只结束这一次尝试。查询级停止还受 turn、取消和预算等机制影响，那些条件由 SDK-01 负责。

执行并回传

  • 规则或宿主允许调用
  • 处理函数返回内容块
  • 后置 Hook 可补上下文或改结果

等待或暂缓

  • 审批回调未返回时执行暂停
  • 查询取消会结束等待
  • defer 可让宿主稍后恢复

阻断或报错

  • deny 规则与 Hook 可拒绝
  • Hook 超时会跳过这次执行
  • MCP 与处理函数错误回到 Claude

拒绝发生在执行以前，处理函数不会收到这次请求。参数校验或处理函数报错发生在执行入口附近，进程内 MCP server 会把它整理成带有错误标记的工具结果。两条路径都能给 Claude 留下反馈，页面仍把它们分开，因为前者说明权限没有放行，后者说明调用已经抵达执行层。 O

本机核对

确认到固定版本

状态保持 documented。本轮安全范围允许读取帮助和安装文件，未获准启动会产生 API 用量的 Agent 调用。

L 级证据

固定版本仍可核

本机保留 Claude Code 2.1.247。版本输出与给定二进制哈希完全一致。

当前默认安装已经前移到 2.1.250，复现时要显式选择旧版本。

实际执行的只读核对

  • 通过　固定二进制版本与 SHA-256
  • 通过　主帮助中的工具面、权限模式、MCP 配置和 Hook 事件流开关
  • 通过　MCP 子命令帮助中的 transport、项目审批和 server OAuth 入口；这不证明 SDK 的模型身份验证
  • 未运行　模型发起工具调用、审批回调和工具结果回传

实现与版本

两个控制面要分开

一个控制模型能看见什么，另一个控制已经提出的调用能不能执行。把允许清单当成工具清单，会留下意外可见的调用面。

可见性

工具面选项只筛内置工具，接口名为 tools。裸名 deny 会把对应工具从上下文移除。MCP 工具由 server 注册与连接状态提供。

调用权限

普通调用命中预批准规则后会跳过交互。ask 规则和要求用户交互的 MCP 工具仍进入回调；plan 模式把写操作送去审批。关键路径上的 rm 与 rmdir 也不能由 allow 规则直接放行，在 auto 模式进入分类器。dontAsk 会把这些待批请求改为拒绝。 O

身份与费用边界

官方 Quickstart 的常规路径要求 Anthropic 账户和 Claude Console API key，SDK 从运行进程的 ANTHROPIC_API_KEY 读取凭据。查询会产生计费 API 用量；本页只标出这个前提，不展开成本计算。第三方产品若未获 Anthropic 事先批准，不得把 claude.ai 登录或额度提供给自己的 Agent SDK 用户。 O

结果怎样回去

两种固定版本都能返回内容块与错误标记。TypeScript v0.3.247 的处理函数还能附带 structuredContent。Python v0.2.145 的进程内 server 只转发 content 与 is_error；Python 若要返回 structuredContent，需要改用独立 MCP server。成功以后，PostToolUse 能补充上下文，固定版本的公开类型还允许它用 updatedToolOutput 替换送回模型的结果。执行失败则进入 PostToolUseFailure。工具错误通常只结束这一次调用，Claude 仍可以依据错误结果重试、改用别的工具或向用户说明失败。 O

语言官方标签本页核对点

证据边界

还差一轮真实调用

这些缺口会改变对时序与覆盖面的判断，页面把它们留在明处。

内置工具的 Hook 覆盖

本轮没有在 2.1.247 上逐个触发内置工具，无法确认每类工具都经过同样的 SDK 回调路径。

并行调用的交错顺序

同一批多个工具请求里，Hook、审批等待和结果返回怎样交错，官方接口给了相关字段，本轮没有运行证据。

MCP 缓存与重连

缓存工具表过期、远端 schema 改变和连接恢复同时发生时，逐帧状态没有在固定版本上测量。

大体积与非文本结果

图像、资源和较大工具结果经过后置 Hook 改写时，两种语言 SDK 的完整兼容矩阵没有逐项验证。
