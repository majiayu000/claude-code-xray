01 / ANSWER

接管的是会话入口

手机获得同一条会话的第二个操作面，可以传入消息和决定，也能接收对话、工具活动与状态；主机继续持有文件、工具和运行进程。

O能做什么

从终端、浏览器和手机交替发消息，处理问题与权限提示，查看进度并停止正在运行的任务。

O什么会同步

对话、Claude 回复、工具活动和连接状态会经 Anthropic 服务同步。连接期间 transcript 会存到服务端。

O什么留在电脑

代码执行、文件访问、本地工具、MCP 服务和项目配置仍由原主机上的 Claude Code 使用。

02 / ROLES

三方各做一件事

角色分开，执行地点和数据去向就清楚了。

⌘_
原主机

运行 Claude Code 进程，接触本地文件与工具，也实际启动命令。

⇄
Anthropic 服务

登记远控会话，在已连接设备之间转发消息并同步 transcript。

▯
远端设备

Claude 移动端或浏览器里的 Code 界面。它是客户端，不是代码运行环境。

03 / SEQUENCE

一次跨设备接管怎样发生

这里沿着已经打开的交互会话往下走。独立的 server mode 留在边界说明中。

01

本机先有一条运行中的会话

工作区已经通过 trust，用户用 claude.ai 订阅账户登录。API key 不能建立 Remote Control。O

02

用户在原会话开启远控

输入 /remote-control 或 /rc。当前对话历史继续沿用，终端给出会话入口。OL

03

本机主动连接 Anthropic

Claude Code 只发出站 HTTPS，请求短期凭据并保持流式连接。本机不开放入站端口。O

04

手机或浏览器进入同一会话

用户扫描 QR 码、打开会话 URL，或在 Code 列表里找到它。登录账户与组织需要一致。O

05

远端输入回到原进程

新消息、问题答案、权限决定和停止动作经服务端转发。本机 Claude Code 接着执行，并把状态同步回各个界面。O

06

断开远控或主机离线

主动关闭远控时，本地交互会话可以继续。Claude Code 进程停止后，远端会话下线；网络恢复时，交互模式会尝试重连。O

仅本机→连接中→远程已连接→断开或离线I
04 / FLOW

四种东西走不同的路

“本地执行”回答工具和文件在哪里处理，连接期间的消息、回复和工具活动仍会经过并存放在 Anthropic 服务端。

远端消息与审批

手机或网页发出，Anthropic 服务转发，本机 Claude Code 接收并推进同一条会话。

经服务端
会话 transcript

消息、Claude 回复和工具活动在连接期间存到 Anthropic 服务器，用于同步与重连。

服务端留存
手机添加的附件

照片直接成为消息的一部分，其他文件会下载到原主机，再以文件引用交给 Claude Code。大小上限与清理周期仍未知。

传到原主机
文件与工具调用

Claude Code 在原主机读取项目文件、调用 MCP 与工具。远端界面看见结果。

原主机
代码与命令

命令由原主机上的进程执行。Remote Control 没有为这条会话创建云端 VM。

05 / GATES

先过四道门，再谈接管

任意一项不满足，远控入口会失败或保持不可用；Team 与 Enterprise 还受组织策略控制。

ACCOUNTclaude.ai 订阅登录
ORG组织已允许远控
WORKSPACE本机已通过 trust
NETWORK可出站访问 API
权限仍归原会话

远端可选 Manual、Accept edits 和 Plan。Auto 与 Bypass permissions 不能从手机或网页端选。

网络中断会等待

交互模式可以继续在本机工作并重连。同步恢复前，远端看不到新的现场状态。

主机进程决定在线状态

关闭终端、退出 VS Code 或停止 Claude Code 进程，远端会话就会下线。

哪些命令仍要回到本地终端

/plugin 和 /resume 这类依赖终端选择器的命令只在本地 CLI 工作。移动端可以使用官方明确列出的文本输出命令，也能给 /model、/effort 等命令直接传参数。

主动断开会发生什么

从终端状态面板或再次运行 /remote-control 可以关闭远控。原来的交互会话继续留在终端。若会话被另一设备接管、归档或删除，重新开启前应先读清失败原因。

Mobile 和 Claude Code on the web 有何区别

Claude 移动端是多个会话来源共用的客户端。Remote Control 指向你的电脑，Claude Code on the web 指向云端运行环境。两者能出现在相似界面里，执行地点不同。

06 / EVIDENCE

研究只做了本机版本、文件哈希与帮助入口核对。真实远控需要订阅登录和另一设备，继续会建立会话，所以本页没有 R。

08 / UNKNOWNS

还有四处没有证实

这些问题会改变弱网、附件和跨平台体验。当前只有官方描述，缺少 2.1.247 的隔离设备实验。

弱网顺序

重连期间消息怎样排队，重复投递怎样处理，本轮没有 R。

移动端差异

iOS 与 Android 当日界面、后台限制和推送延迟没有设备核验。

重连记录

官方没有公布完整字段、落盘位置和清理时机，本轮也没有读取私人状态。

附件边界

2.1.247 的大小上限、重试与本地清理周期缺少完整版本化契约。
