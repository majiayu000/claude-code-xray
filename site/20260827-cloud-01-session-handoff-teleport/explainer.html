CLOUD-01 当前状态 documented Claude Code 2.1.247

接来一份云会话副本

Teleport 要求账号、仓库、本地工作树和云分支同时满足条件。门槛都过了，Claude 把云端分支和完整对话拉进终端。终端从此有自己的副本，后来在本地说的话不会回到原云会话。官方没有承诺这四项的内部核验顺序。O

这页只追踪身份、代码状态、权限和接管。Deep Links、Artifacts 与分享留在边界外。

01 / TERMS

先把证据和角色分开

官方契约能说明产品答应做什么，本机帮助只能说明 2.1.247 带着哪些入口。没有真实云端接力，本页就停在 documented。

O官方契约

Anthropic 文档、帮助与 changelog，用来定支持范围。

L本机证据

冻结的 2.1.247 二进制、哈希和帮助输出。

R真实实验

本轮没有。云端接力会碰真实账号、会话与 Git 状态。

I研究推断

只负责连接已知事实，遇到缺口就停下来标明。

云会话

在 Anthropic 托管 VM 或组织自托管环境运行，保存对话并维护自己的工作分支。O

本地 CLI

发起 Teleport。四项条件满足后，CLI fetch、checkout 并载入对话。O

Git remote 与账号

remote 承担代码交接，claude.ai 账号承担会话访问。两道身份都要对上。O

02 / SEQUENCE

一次接力经过这些阶段

时序从云端已经有会话开始。CLI 创建云任务属于前情，Teleport 的工作从选中那场云会话才开始。

T0 云端工作

云会话持有对话和工作分支

常规云任务从 GitHub remote 的选定分支起步。仓库已提交配置能进去，用户目录里的本机配置留在本机。O

T1 用户选择

用户从终端挑一场云会话

可以运行 Teleport 入口、在会话内打开选择器，也可以从任务列表触发。它列的是云会话，普通 resume 只看本机历史。OL

T2 前置条件

四项并列门槛都要通过

账号必须相同，当前 checkout 要属于同一仓库，本地工作树不能留有未处理的改动，云分支也要能从 remote 取得。任何一项不满足，接力停在这里。官方只列出这些要求，没有公开 CLI 的内部核验次序。O

T3 拉取状态

CLI 拉下分支并载入完整对话

CLI fetch 并 checkout 云端分支，随后载入完整会话历史。代码分支经 Git 取得，官方没有公开对话传输的内部协议。O

T4 本地续做

本地副本从这里独立继续

接管完成后，终端里的新工作留在本地，claude.ai 和移动端的原云会话不会同步这些新消息。需要手机继续操控本机，要另开 Remote Control。O

03 / FLOW

接管之后，状态在这里分叉

会话来源能追溯到云端，后续状态却分成两份。把它当成同步，会在最要紧的地方理解错。

  • 运行环境采用云环境的网络与变量

接力后的终端

  • 完整历史已载入本地副本
  • CLI 已 fetch 并 checkout 对应分支

  • 新消息不回写原云会话

本地副本保留云会话的来源关系。代码由 Git 交接，对话在接管点复制。官方没有说明权限自动迁移。OI

04 / LIMITS

权限门和停止点很具体

Teleport 把本地工作树、仓库、云分支和账号都设为放行门槛。官方没有说明这些门槛按什么次序核验。云环境自己的权限模式与网络隔离仍然影响接力前的工作。

套餐与认证门

Web/Cloud 研究预览面向 Pro、Max、Team，以及有 premium seat 或 Chat + Claude Code seat 的 Enterprise 用户。Teleport 还要求 CLI 登录创建云会话的同一 claude.ai 账号；API key 与第三方 provider 不满足这项认证要求，组织也能关闭云会话。O

Git 门

仓库不匹配、当前 checkout 是 fork、分支未推送，都会阻止接力。本地有改动时，2.1.247 会提出 stash。O

云端权限

Web 提供 Accept edits 与 Plan。Auto 取决于组织和模型，Bypass permissions 在云会话里不可用。O

运行隔离

Anthropic 托管会话处在隔离 VM，网络受环境策略限制，Git 凭据留在沙箱外并由代理代办。O

核验失败

CLI 报错或要求先处理本地状态，分支与对话都不接管。

环境到期

云 VM 被回收。对话可在新环境恢复，仍在跑的 shell 与后台 agent 不会恢复。

接力完成

终端拿到副本后，云端与本地各自继续。双向同步不在这条状态机里。

05 / EXPERIMENT

本机只核到入口，没有冒充接力成功

这轮没有登录、没有打开真实 session picker，也没有 fetch 或 checkout 任何项目。安全边界在这里很清楚。

2.1.247 静态与帮助证据

  • 冻结二进制报告 Claude Code 2.1.247。
  • SHA-256 与任务给定基线完全一致。
  • 帮助同时列出 cloud 与 teleport 两个入口。
  • Teleport 可以打开选择器，也能接受会话标识。

L这些结果只证明本机版本带着入口。

实验停在登录门

真实 Teleport 会读取云会话，可能 stash 改动并切换分支。任务禁止登录、访问私人会话和影响现有工作，因此没有继续。
