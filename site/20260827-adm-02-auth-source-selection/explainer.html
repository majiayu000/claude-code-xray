01 / TERMS

先把三件事分开

登录成功、凭据生效和模型可用发生在不同位置。混在一起看，最常见的误判就是订阅明明有效，终端却还在用另一把 key。

SOURCE

认证来源

Claude 订阅、Console、云提供商或企业 gateway 决定请求先去哪里，也决定该找哪一类身份。

CREDENTIAL

当前凭据

同一个进程可能看见多份凭据。Claude Code 只按优先级拿其中一份发当前请求。O

MODEL GATE

模型门

凭据有效以后，目标账号仍要有该模型、区域、IAM 或 RBAC 权限。allowlist 还会先收窄可选项。O＋I

02 / SEQUENCE

一次启动里的先后顺序

这条时序只写官方材料能承住的部分。环境变量在启动后是否能热切换提供商，公开契约没有给出完整内部时序。

01

用户启动或重新登录

首次运行会打开登录；Bedrock 与 Google Cloud 也可从第三方平台向导进入。

02

提供商先分流

已登录 gateway 优先；随后才看 Bedrock、Google Cloud 或 Foundry 开关。

03

候选凭据排队

Bearer、API key、helper、长期 OAuth、profile 与订阅 OAuth 依次判断。

04

权限与模型过门

组织策略、云端身份、区域和模型部署决定目标模型能否调用。

05

首个请求给出结果

成功才进入模型；过期、无权限或缺部署会在启动或请求处停下。

04 / LIMITS

切换会停在哪里

报错文案会变，失败位置更稳定。先查谁赢。随后再看目标平台是否允许那一个模型。

旧 key 抢先

订阅仍有效，批准过的 ANTHROPIC_API_KEY 仍会盖过它。旧组织停用时，请求报组织错误。

停止点在认证后的 API 请求。清掉变量，再用状态页核对。O

登录已经过期

临近到期三天只显示提醒。登录已经过期并且无法刷新，每个请求都会要求重新登录。

停止点在每次请求。后台任务也会失去进展。O

云端身份没装好

Bedrock、Google Cloud 与 Foundry 分别会报找不到 AWS、GCP 或 Azure 凭据链。

通常停在启动检查或第一条请求，IDE 还可能没有继承 shell 环境。O

模型在别处

区域、模型批准、部署名、IAM 或 RBAC 任一缺口都会挡住模型。Bedrock 与 Google Cloud 可做当次回退，Foundry 直接报错。

回退不会持久保存，固定模型才会让下次启动保持选择。O

05 / EXPERIMENT

本页停在 documented

只读核对到此为止。它能证明程序公开了这些入口，无法证明私人账号当前用了哪条线；后一个问题需要查看认证状态或发出远端请求，本轮没有授权。

O＋L

官方契约和基线二进制互相对过。没有 R，因此页面没有写成 verified。

L

版本与散列一致

固定安装文件输出 Claude Code 2.1.247，SHA-256 与给定基线完全相同。

L

帮助面可见

根帮助公开 auth、setup-token、model、fallback model 与 bare mode；登录帮助公开订阅、Console 和 SSO 入口。

O

官方索引仍有 202 项

8 月 30 日重抓时入口数未变，散列已不同于 8 月 27 日基线。本文保留旧基线，没有把这次变化解释成产品行为。

R

真实账号路径未运行

没有执行状态查询、登录、退出、token 生成、云平台认证或任何模型请求。

06 / IMPLEMENTATION

四个会改变结果的细节

这些细节都来自公开契约。展开阅读时仍要记住，本页没有观察内部函数或私人状态文件。

API key 的批准门

交互模式第一次看见环境 key 时会让用户接受或拒绝，选择会被记住。非交互 -p 只要看见 key 就使用它。

O / Authentication precedence

helper 的刷新与停止

默认五分钟或 HTTP 401 后重新取 key。helper 报错、超时或空输出，会在三次尝试内让请求失败。

O / Credential management

模型固定与当次回退

三方部署没有固定版本时，别名会跟随 Claude Code 的提供商默认值。Bedrock 与 Google Cloud 可为当前会话回退，Foundry 没有启动检查。

O / Model configuration

长期 OAuth 的回摆

当前会话执行登录后可以换到新账号。shell 里的长期 OAuth 变量还在，下一次启动又会读回它。要让切换保持，必须删掉更高优先级的旧来源。

安全复现办法

  1. 固定版本后只看版本与帮助，不执行认证状态查询。
  2. 获准使用隔离账号时，一次只放入一种凭据，并在状态页记录来源类别。
  3. 模型失败实验只在有成本上限的测试资源里做，记录匿名化错误类型，不保留 token、邮箱、组织 ID、资源名或真实工作目录。
  4. 得到 O、L、R 三层互证以后，再把状态改为 verified。
