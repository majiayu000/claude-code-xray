让页面跑起来，再把问题送回来

Desktop 会启动项目的开发服务器，也能接到一个已经运行的地址。页面进入内嵌预览后，Claude 读取截图、DOM 和服务器日志，用户可以直接操作页面，再把看到的问题写进同一会话。下拉菜单负责停掉单个或全部预览服务器。 O＋I

本页有官方契约，没有付费 Desktop 会话的真实运行证据。反馈回路里，页面观察与提示框纠正各有官方依据；两者之间的内部载荷没有公开，所以状态保持 documented。

SEQUENCE

六步走完一次预览

起点是已有 Desktop 会话与项目目录。工作区怎样建立留给 UI-05，本页从用户要求预览或自动核验开始。

01

触发预览

Claude 改完文件后通常自动启动。用户也能随时要求预览，或从下拉菜单手动启动。 O

02

读取配置

Desktop 在项目根目录探测并保存 .claude/launch.json。自定义命令与端口可在这里改。 O

03

启动或接入

有命令就启动开发服务器。配置只写 URL 时，Preview 接入用户已经运行的服务。 O

04

等待页面

默认地址指向 localhost 与配置端口。端口冲突会自动换、直接失败，或先问用户。 O

05

读取状态

Claude 可看截图、DOM 与服务器日志，也能点击元素和填写表单。用户仍可直接操作页面。 O

06

反馈或停止

用户把观察写进同一提示框，Claude 下一步再修。下拉菜单可停止单个或全部服务器。 O＋I

配置留在项目里

.claude/launch.json 记录运行命令、端口与相对 cwd。官方提醒不要把秘密写进它，因为文件会进入仓库。预览服务器要用秘密时，应放进 Desktop 的本地环境编辑器。 O

浏览状态可以另存

Persist sessions 会让 cookie 与 local storage 跨服务器重启保留。用户可从设置清除保存状态。具体存储位置与隔离键仍未公开。 O＋I

LIMITS

先过账号门槛，再看预览能否接通

Code tab 要求登录 Anthropic 账号并使用付费计划。进入会话以后，服务器命令、目标地址和端口还会分别让流程停住。停止 Preview 服务器也不等于结束整个 Claude 会话。

ACCESS先登录 Anthropic 账号。Code tab 若提示升级，用户还要先订阅 Pro、Max、Team 或 Enterprise 计划。 O
COMMAND权限模式控制 Claude 是否要先询问再运行命令。工具不在 PATH 时，开发服务器无法启动。 O
ADDRESSlocalhost 与项目文件无需外站许可。外部地址第一次打开要用户批准，组织策略仍可拦截。 O
PORTautoPort 开启后改用空闲端口，关闭后直接失败，未设置时先问用户。 O

停止分成三件事

下拉菜单能停止选中的服务器，也能一次停止全部服务器。设置里还能关闭整个 Preview 功能。只写 URL 接入外部服务时，停止动作是否会尝试影响那个外部进程，官方没有说明。稳妥复现时要另查端口和进程。 O＋I

EXPERIMENT

这次没有启动付费会话

只读检查遇到两个明确边界，命令入口不在当前 shell 的 PATH，系统也拒绝读取 Desktop 应用包。

实际执行的只读检查

claude --version、claude --help 和登录 shell 重试都返回 command not found。标准应用候选路径可解析，读取可执行文件与 Info.plist 时被系统拒绝。 L

它不能证明 Preview 跑过

阴性结果只说明研究 shell 无法复核固定基线。进入 Code tab 必须登录 Anthropic 账号并使用 Pro、Max、Team 或 Enterprise 计划。本轮没有检查登录态或订阅状态，也没有新建可能消耗额度的会话，因此 Local、Cloud、SSH、WSL、macOS 与 Windows 都没有 R。

自动核验

默认每次编辑后运行。项目可在配置里写 autoVerify false，也可从菜单关闭。关掉以后，用户仍能要求 Claude 手动核验。 O

版本名称漂移

固定基线使用 App Preview。2026-08-30 的英文参考已把部分界面称为 Browser pane，配置节仍叫 Preview。复现时应同时记下页面日期和界面用词。 O

项目如何进入会话、worktree 怎样隔离、pane 怎样布置，都由 UI-05 Desktop 项目会话与隔离工作区 说明。本页只接住它留出的 App Preview 边界。

UNKNOWNS

公开资料留下五个缺口

它们会改变停止与反馈的精确解释，页面没有用示意图替它们作答。

元素选择怎样进入会话

官方只列出选择元素快捷键，没有公开 DOM 路径、坐标、截图或序列化字段。

URL-only 服务怎样停止

只写 URL 时，Desktop 连接用户已经运行的服务。停止菜单会断开视图还是影响外部进程，公开资料没有说明。

自动探测采用什么判定

官方说明会自动探测并写配置，没有给出候选命令顺序、冲突规则与刷新时机。

异常退出怎样呈现

服务器崩溃、健康检查超时和日志过长是否进入不同错误状态，目前没有完整公开表。

Persist sessions 存在哪里

官方保证 cookie 与 local storage 可以跨重启保留，也提供清理开关。存储位置、加密与隔离粒度没有公开。
