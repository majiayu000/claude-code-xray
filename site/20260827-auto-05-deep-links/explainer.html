01 / TERMS

四种证据，四个角色

这页有完整官方契约，也有本机失败观察。没有让协议处理程序实际启动产品，所以状态停在 documented。

O 官方契约

Anthropic 文档与 changelog，负责公开行为和版本边界。

L 本机观察

当前 shell 找不到 claude，官方列出的用户级 handler 与安装目录也不存在。

R 真实实验

本轮没有。没有打开 handler，也没有发送付费 prompt。

I 研究推断

只连接已知停止点，不补内部调用顺序。

链接发布者

把 surface、目录线索和预填任务编码进 URI。链接可放在支持自定义 scheme 的页面或工具里。O

系统与 handler

浏览器把 URI 交给操作系统，系统再启动已注册的 Claude Code 处理程序与终端。O

点击链接的人

核对外部 prompt，必要时修改或清空。只有他按 Enter，任务才进入会话。O

02 / SEQUENCE

一次点击怎样变成会话

顺序里有两个独立的门。URI 先过格式与目录校验，用户随后决定要不要发送预填任务。

T0 编码

发布者组好 URI

claude-cli://open 指向终端面。q 放 URL 编码任务，cwd 或 repo 选择起始目录。两者同时出现时，cwd 优先，哪怕路径不存在，repo 也会被忽略。O

T1 分派

浏览器交给操作系统

系统只有在 handler 已注册、渲染平台又保留自定义 scheme 时才有东西可启动。GitHub Markdown 会先把这类链接剥掉。O

T2 校验

处理程序检查 path 与参数

只接受 open。网络或 UNC 的 cwd、含不可见或双向控制字符的路径会被拒，q 上限为 5,000 字符。O

T3 打开

新终端拿到目录和预填任务

repo 会落到最近用过的匹配 clone 或 worktree。没有匹配项就回到 home，已有分支保持不动。O

T4 确认

外部来源提示一直留着

用户可以检查、修改或清空输入。长于 1,000 字符时界面还会显示字符数并提醒滚动阅读。O

T5 发送

按 Enter 后才进入正常权限链

目标目录的 trust、CLAUDE.md 和权限规则照常生效。链接没有获得额外通行证。O

04 / LIMITS

失败点分布在打开前后

格式错误与目录风险由 handler 处理。账号、计费和工具授权沿用当前 Claude Code 会话的规则，要等用户发送任务以后才会发生模型用量。

Path 门

只有 open 被接受。网络、UNC、不可见字符与双向控制字符会让 cwd 被拒。O

Query 门

q 必须 URL 编码，最多 5,000 字符。超过上限的精确错误文案没有公开稳定契约。OI

User 门

prompt 保持未发送。用户看过外部来源提示以后，可以修改、清空或按 Enter。O

Authority 门

链接只能选目录并填文字。workspace trust、项目规则与工具权限仍按目标目录正常判断。O

账号门

链接不携带登录资格。可用入口包括 Pro、Max、Team、Enterprise、受邀的 Console 账号，以及组织配置的 Bedrock、Google Cloud Agent Platform 或 Microsoft Foundry。未完成认证时，客户端仍要走正常登录或组织认证。O

费用门

点击和预填不会产生模型请求。按 Enter 后才开始按当前登录方式计量。订阅用户按计划额度使用，其中 Pro 与 Max 使用个人额度，Team 与 Enterprise 使用成员席位额度。Console 与云提供商按 token 向组织计费。O

没有 handler

点击可能没有反应。官方要求先在交互会话里发送首个 prompt 来完成注册。

找不到 repo

会话回到 home，不会替用户 clone，也不会切换当前分支。

渲染器剥离 scheme

GitHub 页面只留下链接文字，URI 本身不会传给操作系统。

05 / EXPERIMENT

本机没有跑到产品路径

当前研究 shell 没暴露 Claude CLI，官方列出的用户级 handler 与安装目录也不存在。结果只能算本机负证据。

执行过的只读检查

claude --version 与 claude --help 都返回 command not found。官方列出的用户级 handler 与固定安装目录均不存在。L

它证明当前研究环境不能直接核对 2.1.247，不足以判断其他安装位置或系统注册数据库里的状态。

为什么停下来

调用系统 URL opener 会启动 GUI、终端或登录流程，还可能影响正在使用的桌面状态。任务不允许启动付费会话或碰真实会话，本轮没有触发。

07 / UNKNOWNS

还不能写死的地方

这些缺口会影响错误恢复或安全判断。官方没承诺，本轮也没有运行，所以页面到这里收住。

UNKNOWN 01不存在的 cwd

它会不会先打开终端，最终显示什么错误，官方主契约没有说清。

UNKNOWN 02重复 query 参数

多个 q、cwd 或未知参数怎样取舍，公开文档没有规定。

UNKNOWN 03本地路径竞态

符号链接、alias、大小写差异与点击后路径被替换怎样处理，官方没有公开。

UNKNOWN 04跨平台错误界面

系统确认框、终端选择失败和 URL 解码错误的精确文案没有形成统一契约。

UNKNOWN 05系统确认差异

Linux 各桌面与 Windows 各 shell 怎样提示自定义 scheme，本轮没有覆盖。
