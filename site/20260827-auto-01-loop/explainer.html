会话内定时器 · 官方契约与本机静态核对

/loop 到点只排队

活跃会话就是它的执行边界。间隔到期时，任务先进入低优先级队列。Claude 还在回答，下一轮就等到当前回合结束，不会重叠开跑，错过的多个间隔也只补一次。固定间隔任务按 ID 取消，自定节奏任务也能由 Claude 或用户停下。退出后不再触发，恢复原会话时未过期任务可能回来。 O

SESSION OPEN到点 → 排队 → 空闲后执行
01 / TERMS

先分清两种循环

固定间隔

/loop 5m 检查部署 会转成五字段 cron，创建后给出频率和八字符任务 ID。它一直按计划等候，直到取消、到达七天期限或会话停止触发。 O

自定节奏

/loop 检查部署 让 Claude 每轮根据观察结果选择下一次等待，范围是一分钟到一小时。结束时会显示等待多久及原因，工作做完后 Claude 可以主动停止。 O

本页的状态转换

当前会话接纳循环任务，等待到期后把提示变成下一回合；会话忙时延后且合并漏掉的时点，任务经取消或过期后停止，关闭进程后也不再触发。

任务

保存提示、日程、是否重复及 ID 的会话级条目。一次会话最多 50 个。 O

回合

一次用户输入到 Claude 完成回复的工作段。定时提示只能在两个回合之间进入，不能在回复中途插进来。 O

02 / SEQUENCE

一次循环怎样走完

  1. 用户交代间隔和提示

    间隔和提示都可省略。省略间隔会进入自定节奏，省略提示会使用内置维护提示，项目或用户的 loop.md 可以替换这个默认。 O

  2. 技能解释输入

    固定间隔会换算为 cron。秒数向上取整到分钟，无法整除日程的间隔会被调到可表示的邻近值，Claude 会告诉用户最后采用什么。 O

  3. 调度器登记

    固定任务由 CronCreate 登记。创建结果显示频率和任务 ID。自定节奏用 ScheduleWakeup 留下下一次唤醒。2.1.247 安装文件同时含有这些工具名和输入说明。 OL

  4. 本机等待

    固定任务由调度器每秒检查。时间按本机时区解释，重复任务还有由任务 ID 决定的固定抖动。 O

  5. 到点进入低优先级队列

    这一步只安排下一条提示。Claude 若在处理中，提示等到本回合结束。期间错过多个时点也只在空闲后触发一次。 O

  6. 沿用当前会话执行

    任务能访问会话可见的本地文件和 MCP，权限提示也沿用会话规则。执行结果成为同一段对话里的下一轮内容。 O

  7. 再等一次或停止

    固定间隔继续等下一时点。自定节奏会选择一分钟到一小时的下一次等待，也能判断工作已经完成并停止。某一轮既没重新安排，也没明确停止，Claude Code 约二十分钟后兜底唤醒一次；这一轮仍不安排下一次，循环便结束。 O

输入流

提示文字进入任务条目。裸命令会在每轮读取优先级最高的 loop.md，文件改动从下一轮生效，超过 25,000 字节的内容会截断。 O

时间流

固定 cron 按本机时间计算，并带有确定性抖动。当前官方页面与归档 2.1.247 安装说明给出的精确上限不同，本页不替 2.1.247 选定其中一套公式。 OLI

结果流

定时提示只在回合之间送入对话。它会经过原会话的工具和权限边界，涉及写入、推送或删除时仍可能停在批准处。 O

04 / LIMITS

哪里会停，哪里只会等

情形结果证据

自定节奏正在等待用户按 Esc 可清掉待唤醒，Claude 也能用停止参数结束。固定 cron 不受这个 Esc 动作影响。O

登录和费用跟着现有会话走。 Claude Code 支持订阅账号、Console API 凭据和云提供商等认证方式；/loop 的官方指南没有另列登录或套餐门槛，也没有公布每轮怎样计入用量或费用。本页只能确认它在已打开的当前会话中运行，不能把某一种计费方式写成通则。长期可靠运行应交给云端 Routines、Desktop Scheduled Tasks 或 GitHub Actions。 OI

05 / OBSERVATION

本机只做了静态核对

归档的 2.1.247 可执行文件报告 2.1.247 (Claude Code)，SHA-256 与基线给定值完全一致。它的公开帮助列出恢复与继续会话的参数；安装文件静态字符串包含 /loop 用法、三个 Cron 工具、ScheduleWakeup 和禁用环境变量。 L

当前命令链接已指向 2.1.250。研究没有把当前链接的行为倒算到 2.1.247，也没有启动新的 Claude 会话。这样避开了付费调用、私人会话和全局状态改动。缺少真实触发结果，页面状态保留为 documented。 L

本轮执行过的安全命令

归档二进制 --version、归档二进制 --help、shasum -a 256 归档二进制，以及对安装文件做限量的公开功能字符串筛选。没有读取任何会话记录或私人配置。

06 / VERSION

2.1.247 的实现边界

公开工具面

CronCreate 接收五字段 cron、提示和是否重复。CronList 显示 ID、日程和提示，CronDelete 按 ID 删除。自定节奏另用 ScheduleWakeup。 OL

2.1.247 之后的一步

2.1.248 才把自定节奏和无提示默认扩展为所有提供商始终可用。处在 Bedrock、Vertex、Foundry 或关闭功能标志抓取的 2.1.247 会退到旧行为，无间隔提示固定十分钟，裸 /loop 显示用法。 O

技能调用门

定时提示里的技能只有在 Claude 可自主调用时才执行。内置命令、禁止模型调用的技能、被规则隐藏的技能和 MCP prompt 会作为普通文字进入 Claude。 O

显示面

固定任务创建时显示采用的节奏和 ID，列表显示所有任务的 ID、日程和提示。自定节奏每轮末尾显示下一次等待及理由。 O

07 / UNKNOWNS

还没有证实的七件事

I官方没有公开 2.1.247 会话级任务在各平台上的完整落盘格式、锁策略与崩溃一致性。

I本轮没有测量调度器忙碌时从回合结束到提示实际进入模型的额外延迟。

I本轮没有在 50 个任务上限处观察具体错误文案，也没有核对删除失败后的界面状态。

I恢复任务时，抖动偏移和下一次触发点怎样重算，没有用 2.1.247 做运行核对。

I当前官方页面与 2.1.247 安装说明给出的抖动上限不同，基线版本实际采用哪套公式没有 R。

I权限提示长时间无人处理时，后续多个到期点怎样显示，只能确认它们不会在忙碌回合里并发执行。

I官方没有给 /loop 单列登录或套餐门槛，也没有公开每轮在订阅、Console API 与云提供商认证下怎样计入用量或费用。

  1. 先核对版本和二进制摘要。
  2. 在获准的隔离会话创建一分钟固定循环。

  4. 列出任务、记录 ID、取消，再确认列表为空。
  5. 另测自定节奏的 Esc、主动停止、二十分钟兜底和恢复边界。
