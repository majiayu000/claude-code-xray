25 / Extension system

工具先可见，连接未必先发生

Claude Code 先核对 MCP 配置与信任。没有缓存时，它会连接 server 并读取能力。远端 HTTP 或 SSE server 命中 discovery cache 时，Claude Code 会先采用上次的工具列表，直到首次调用才连接。裸工具名或 mcp__* deny 会先删掉候选，剩下的定义再由 Tool Search 按需装入。

调用阶段还要处理认证与许可。关闭 Tool Search、代理不支持 tool reference，或把 server 标成 alwaysLoad，会改变 schema 进入上下文的时机。

01 / TERMS

四个词够用了

server 提供能力，Claude Code 负责读取或复用列表，Tool Search 决定何时装入 schema，权限规则同时影响可见性与调用。

MCP SERVER

能力提供方

可以是本机 stdio 子进程，也可以是 HTTP、SSE 或 WebSocket 远端服务。

DISCOVERY

能力列表

通常连接后读取 tools、prompts 与 resources。缓存命中时，远端 server 的旧工具列表可先供本次会话使用。

TOOL SEARCH

按需装入

默认只把工具名与 server instructions 放进起步上下文，需要时再取完整 schema。

PERMISSION

两处分流

裸名 deny 在模型看到工具前过滤候选。带范围的 deny、ask 与 allow 留到调用时处理。

02 / SEQUENCE

两条发现路在调用处汇合

用户先添加配置。新鲜发现会连接并枚举，缓存发现会先拿到旧工具列表。两条路都要经过可见性过滤、Tool Search 与调用许可。

记录 server

CLI 或 .mcp.json 写下 transport、endpoint、启动命令与作用域。

角色 · 用户与配置层

检查信任

project server 在交互会话首次使用前等待批准。拒绝或停用会在这里停止连接。

状态 · pending 或 approved

取得能力列表

新鲜发现连接后枚举。缓存发现复用远端 server 上次的工具列表，此时可以尚未连接。

分支 · live 或 cached

过滤并搜索

裸名 deny 先移除工具。模型从余下名称中搜索候选，ToolSearch 再装入完整 schema。

停止 · hidden 或 deferred

补连并调用

停止 · result、deny、auth 或 timeout

04 / LIMITS

门关在哪里

配置存在、列表可用、模型看见、连接成功与调用获准是五个状态。缓存和 deny 都会让它们脱离固定顺序。

项目批准与组织政策

未批准的 project server 不连接。管理员还可按 URL、启动命令或名称限制 server，deny 优先。

认证与 401、403

远端 server 可进入 needs authentication。交互会话从 /mcp 发起 OAuth，命令行也有 claude mcp login。非交互运行不能弹出 /mcp 流程。

可见性与调用许可

裸工具名或 mcp__* deny 会把匹配工具移出模型上下文。带范围的 deny、ask、allow 与需要真人确认的工具标记在调用时生效。

登录与套餐

Claude Code 需要有效的认证与计费路径。订阅登录覆盖 Pro、Max、Team 与 Enterprise，也可走 Console、云平台或组织网关。claude.ai connectors 只在订阅登录生效时由本机拉取，Team 和 Enterprise 只有管理员能添加。

连接与发现失败

首次 HTTP 或 SSE 短暂错误最多重试三次。远端中途断开最多重连五次，stdio 不自动重连。能力枚举也有自己的重试边界。

时间与输出上限

工具调用受 wall-clock、首字节与 idle timeout 约束。单次输出超过 10,000 tokens 会提示，默认上限为 25,000 tokens。

上下文成本

默认起步成本来自工具名和 server instructions。完整 schema 在找到工具后进入上下文，工具结果随后继续占用；/context all 可查实际占用。

本页覆盖的界面

主链按终端交互会话与本地配置的 server 描述。VS Code、JetBrains、Desktop、本地 SSH、Web 云会话、headless 与 Agent SDK 都没有 R 级验证。claude.ai connector 在这些界面的交付方式也不相同。

按状态往回查

先在 /mcp 看 server 状态和工具数。Pending approval 指向项目批准，needs authentication 指向 OAuth。cached 表示工具列表已可用，server 会在首次调用时连接；connected 后工具数仍是零，问题才落到能力枚举。

工具数大于零，模型仍找不到时，先查裸工具名与 mcp__* deny，再查 Tool Search 开关、模型支持与代理是否传递 tool reference。ToolSearch 已装入定义，调用却没有送到 server，才检查带范围的 deny、ask 和 allow 规则。

这套顺序能保留每个停止点。重新添加 server 只会重走配置与连接，无法替代 OAuth，也不会越过工具权限。远端重连、发现重试和一次工具调用的超时也各有上限，等待不会让所有失败自动恢复。

我对了 CLI 版本、帮助与官方索引。没有连接真实 server，也没有启动付费 Claude 会话。原因很直接，机器在研究开始前已经从固定基线升级了。

官方 llms.txt 仍有 202 个入口，2026-08-28 在线摘要也已改变。页面因此保持 documented。

06 / IMPLEMENTATION

配置开关怎样改路径

这里列影响主链的差异。它们会改变列表来源、工具可见性、装入时机与首次连接位置。

设置或环境装入与等待代价或限制证据
默认工具定义按需发现，ToolSearch 同时等待连接中的 server。起步只装工具名与 server instructions。O
MCP_DISCOVERY_CACHE=1远端 HTTP 或 SSE server 可复用旧工具列表，首次调用才连接。需要已有缓存；2.1.221 起支持。O
裸名 deny匹配工具在 Tool Search 前移出模型上下文。带范围的 deny 留到调用时裁决。O
ENABLE_TOOL_SEARCH=auto定义累计到上下文窗口的 10% 前预载，余项推迟。在 auto 后附百分比参数可以改阈值。O
ENABLE_TOOL_SEARCH=false全部工具定义提前装入，等待交给 WaitForMcpServers。工具多时会提前吃掉上下文。O
alwaysLoad指定 server 或工具从起步时可见，启动可等连接。每个预载 schema 都占上下文。O
非一方 base URL默认回退预载，显式 true 可尝试转发 tool reference。代理不支持时请求会失败。O
safe mode自定义 MCP servers 停用。管理策略仍可生效。L
07 / UNKNOWNS

证据还没走到这些地方

下面几项会改变实际体验，官方没有公开全部细节，本轮也没有安全地在 2.1.247 上重放。

  1. 固定 2.1.247 在研究当日是否启用了 discovery cache rollout，以及本机当时有没有可用缓存项。
  2. Tool Search 使用的搜索词、候选排序与一次装入多少个工具定义。
  3. 具体 server 的握手耗时、枚举返回顺序与网络重试时间。
  4. OAuth token 在当前操作系统上的具体安全存储位置和加密实现。
  5. 混合文本与图片结果经过限制、落盘和上下文整形时的精确次序。
